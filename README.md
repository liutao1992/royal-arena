# 皇室竞技场 · Royal Arena

一款受实时卡牌塔防玩法启发的独立浏览器游戏。使用 React 19 与 Vite 6 构建，包含圣水循环、双路推进、自动寻敌、弹道攻击、范围法术，以及带不同战术风格的 10 关战役。

**在线体验：** [https://5ybpzra7p3zaq.ok.kimi.link](https://5ybpzra7p3zaq.ok.kimi.link)

## 游戏特色

- **实时卡牌对战：** 管理圣水、循环手牌，在两条线路部署部队或施放火球。
- **完整战斗系统：** 部队会自动寻敌、移动和攻击，远程攻击具有真实弹道与命中判定。
- **战术型对手：** 10 个关卡分别侧重攻城、人海、法术、反击、冲锋、分路与组合推进。
- **战役进度：** 获胜解锁下一关，每关保存最高皇冠数，共可收集 30 颗星。
- **战斗辅助：** 提供战术提示、战斗记录、伤害统计、音效、表情，以及城楼待机和攻击动画。
- **桌面与触屏操作：** 支持点击部署和拖拽出牌，可暂停、静音及全屏游玩。

## 快速开始

安装依赖并启动开发服务器：

```bash
npm install
npm run dev
```

根据终端显示的地址在浏览器中打开游戏。开发服务器支持通过 CLI 参数指定监听地址与端口，例如：

```bash
npm run dev -- --host 0.0.0.0 --port 7100
```

### 构建与本地预览

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## 操作与规则

1. 点击一张手牌，再点击竞技场中的目标位置；也可以直接将卡牌拖入场地。
2. 部队通常只能部署在己方半场，不能放在河道中；摧毁敌方公主塔后，可在对应线路获得额外部署区域。
3. 法术可以投放到场地中的有效位置，不受己方半场限制。
4. 圣水上限为 10，会随时间恢复；常规时间最后 60 秒进入双倍圣水阶段。
5. 摧毁皇家塔获得皇冠，直接击倒国王塔可立即获胜。常规时间结束时，皇冠较多的一方获胜。
6. 皇冠相同时进入 60 秒突然死亡；若加时结束仍未分胜负，则比较双方皇家塔剩余生命值。
7. 胜利后解锁下一关。战役进度保存在浏览器 `localStorage` 的 `royal-arena-campaign` 中，清除浏览器站点数据会重置进度。

## 测试与平衡模拟

运行战斗引擎和 10 关策略测试：

```bash
npm test
```

运行自动对战平衡模拟：

```bash
npm run test:balance
```

平衡模拟会生成 `balance-report.json`，包含各关卡胜率、对局时长、皇冠、圣水浪费和卡牌使用统计；该文件已被 `.gitignore` 排除。

## 项目结构

```text
royal-arena/
├── public/assets/          # 游戏图像与动画素材
├── scripts/                # 引擎、策略与平衡测试
├── src/
│   ├── App.jsx             # 游戏界面与输入交互
│   ├── main.jsx            # React 入口
│   └── game/
│       ├── engine.js       # 战斗模拟、规则与状态更新
│       ├── data.js         # 卡牌、部队与皇家塔数值
│       ├── levels.js       # 战役配置与本地进度
│       ├── renderer.js     # Canvas 场景与特效渲染
│       ├── sprites.js      # 素材加载与动画帧管理
│       ├── ai.js           # 对手策略与战术提示
│       └── audio.js        # 游戏音效
├── index.html
├── package.json
└── vite.config.js
```
